1. Project Overview

Vision

To democratize agricultural technology and provide Indian farmers with AI-powered tools that were previously accessible only to large-scale agricultural enterprises.

Mission

  • Reduce crop losses through early disease detection
  • Optimize water usage with smart irrigation alerts
  • Increase farmer income through data-driven crop recommendations
  • Simplify access to government agricultural schemes
  • Break language barriers with multilingual voice interaction

Problem Statement

Indian farmers face multiple challenges:

  • Lack of timely disease detection leading to crop losses
  • Inefficient water usage due to unpredictable weather
  • Limited awareness of suitable crop alternatives
  • Complex government schemes with poor accessibility
  • Language barriers in accessing digital agricultural tools

Solution

AgriVikas provides an all-in-one platform that combines:

  • AI-powered disease detection using computer vision
  • Real-time weather-based irrigation recommendations
  • Personalized crop advisory based on soil, climate, and market conditions
  • Simplified government scheme discovery
  • Voice-based interaction in local languages

2. Core Features

2.1 Voice Chatbot (Multilingual AI Assistant)

Description: An intelligent voice-enabled chatbot that understands and responds in English, Hindi, and Punjabi.

Key Capabilities:

  • Speech Recognition: Converts farmer's voice input to text in their preferred language
  • Intent Detection: Automatically identifies user queries (disease detection, irrigation, schemes, crop advice)
  • Contextual Responses: Provides relevant answers based on farmer profile and real-time weather data
  • Text-to-Speech: Reads responses aloud in the selected language with voice selection and fallback mechanisms
  • Quick Actions: Pre-defined buttons for common queries

Technical Implementation:

  • Web Speech API for voice input/output
  • OpenRouter AI (DeepSeek Chat model) for natural language understanding
  • Custom intent detection algorithm with multilingual keyword matching
  • Real-time weather context integration

2.2 Disease Detection (AI-Powered Image Analysis)

Description: Advanced computer vision system that analyzes crop leaf images to detect diseases with high accuracy.

Key Features:

  • Single Image Analysis: Upload one image for quick diagnosis
  • Ensemble Analysis: Upload multiple images for higher accuracy through AI voting
  • Blur Detection: Automatically rejects low-quality images
  • Grad-CAM Visualization: Highlights affected areas on the leaf
  • Confidence Scoring: Provides reliability percentage for each diagnosis
  • Treatment Recommendations: Offers cultural, organic, and chemical treatment options
  • Nutrient Deficiency Detection: Identifies soil nutrient issues (N, P, K)
  • Cost Estimation: Calculates treatment costs and potential yield impact

AI Model:

  • Primary: GPT-4 Vision (OpenAI) - Superior image analysis accuracy
  • Fallback: Claude 3 Opus (Anthropic) - Alternative vision model
  • Ensemble Voting: Combines multiple AI predictions for higher confidence

Supported Diseases:

Leaf Blight, Rust, Powdery Mildew, Bacterial Spot, Early Blight, Late Blight, Healthy crop detection

2.3 Smart Crop Advisory

Description: Data-driven crop recommendation system that suggests optimal crops based on soil type, water availability, weather conditions, and market profitability.

Input Parameters:

  • Land area (acres)
  • Soil type (Sandy, Loamy, Clay, Black Soil)
  • Current crop
  • District/Location
  • Water availability (High, Moderate, Low)
  • Current weather conditions (real-time)

Output:

  • Recommended Crops: 3-4 alternative crops with detailed benefits (water savings, soil health, profit potential)
  • Advisory Points: 4-5 actionable recommendations
  • Crop Comparison Table: Side-by-side comparison of 5 crops

2.4 Irrigation Alerts (Weather-Based Recommendations)

Description: Smart irrigation scheduling system that provides real-time recommendations based on current weather conditions and forecasts.

Features:

  • Current Weather Display: Real-time temperature, humidity, and conditions
  • Irrigation Recommendation: Clear advice on whether to irrigate today
  • Days Until Next Irrigation: Countdown based on weather forecast
  • Water Conservation Tips: Practical advice for efficient water usage
  • Rainfall Alerts: Notifications about upcoming rain

2.5 Government Schemes (Personalized Recommendations)

Description: Intelligent system that filters and recommends relevant government agricultural schemes based on farmer profile.

Featured Schemes:

  • PM-KISAN (Direct income support)
  • PMFBY (Crop insurance)
  • Soil Health Card Scheme
  • Pradhan Mantri Krishi Sinchai Yojana (Irrigation)
  • Paramparagat Krishi Vikas Yojana (Organic farming)
  • And many more...

3. Technical Architecture

Frontend Architecture

  • Framework: React 18 with TypeScript
  • Build Tool: Vite
  • Routing: React Router
  • Styling: Tailwind CSS
  • UI Components: Shadcn UI
  • Animations: Framer Motion
  • State Management: Convex React Hooks

Backend Architecture

  • Backend-as-a-Service: Convex
  • Runtime: Node.js
  • Database: Convex Database (Real-time, serverless)
  • Authentication: Convex Auth with Email OTP

4. AI Integration

AI Models Used

1. DeepSeek Chat (Primary Text Model)

  • Provider: OpenRouter AI
  • Use Cases: Voice chatbot responses, Crop advisory recommendations, Government scheme reasoning
  • Advantages: Cost-effective, Fast response times, Good agricultural terminology understanding, Multilingual support

2. GPT-4 Vision (Primary Vision Model)

  • Provider: OpenRouter AI (OpenAI)
  • Use Cases: Disease detection from crop images, Leaf symptom analysis, Grad-CAM focus region identification
  • Advantages: Superior image analysis accuracy, Detailed disease descriptions, Reliable confidence scoring, Nutrient deficiency detection

3. Claude 3 Opus (Fallback Vision Model)

  • Provider: OpenRouter AI (Anthropic)
  • Use Cases: Backup for GPT-4 Vision failures, Alternative disease analysis
  • Advantages: High-quality image understanding, Detailed reasoning, Reliable fallback option

5. Security & Authentication

  • Authentication Method: Email OTP (One-Time Password)
  • Session Management: Convex Auth with secure token handling
  • Data Privacy: User data encrypted and stored securely in Convex database
  • API Security: Environment variables for API keys, Server-side API calls only

6. Multilingual Support

  • Supported Languages: English, Hindi, Punjabi
  • Implementation: LanguageContext with translation function
  • Voice Support: Speech recognition and text-to-speech in all three languages
  • UI Translation: All static text and dynamic content translated
